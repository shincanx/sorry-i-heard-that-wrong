The funniest one-line apology a smart speaker gives after mishearing its owner — 118 characters, in the device's own voice: it heard "play something relaxing" and started the 3 a.m. existential crisis playlist instead.

> Apologies — I heard 'play something relaxing' and started your 3 a.m. existential crisis playlist. We're on track two.

`main.py` is deterministic, uses no network and no dependencies. It writes that one line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, else `/output`).

## Run it

```sh
python3 main.py
```
